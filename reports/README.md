# Submission materials

These Markdown sources cover the challenge package without committing restricted
data:

- `business_technical_summary.md`: concise two-page summary;
- `technical_report.md`: 6–10 page report source;
- `presentation.md`: seven-slide presentation source; and
- `planner_view_template.md`: one-page review checklist and interpretation guide.

`scripts/run_hybrid.py` generates a data-specific `planner_view.md` and detailed CSV
inside the chosen run directory. Those artifacts may contain approved challenge
identifiers and should not be committed unless the data owner approves them.

Before submission, replace every clearly marked real-data placeholder only with
metrics generated by the common pipeline. Do not copy solver-native objective values
or raw QUBO energies into business comparisons.
